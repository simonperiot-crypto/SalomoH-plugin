# IFMY VOX

Plugin d'insert voix par IFMY — AU / VST3 pour macOS (Apple Silicon + Intel), construit avec JUCE.

- **Autotune** : 12 tonalités, 48 gammes (majeures, mineures, modes, pentatoniques, blues, orientales, jazz, japonaises, accords…), vitesse de correction (du naturel au hard tune), intensité, humanize, transposition ±12.
- **Chaîne d'effets** : gate, EQ (low cut, boue, présence, air), de-esser, compresseur, saturation à lampe, doubleur stéréo, delay synchronisé au tempo (ping-pong), reverb.
- **10 presets** : IFMY Signature, Hard Tune (Trap), R&B Soyeux, Pop Brillante, Afro / Amapiano, Naturel (Live), Robot, Lo-Fi Bedroom, Grosse Salle, Voix seule.

Compilé automatiquement par GitHub Actions à chaque push dans `vox/` :
onglet **Actions** → **Build IFMY VOX** → dernier build → **IFMY-VOX-mac** (zip). Instructions dans `INSTALL.txt`.
